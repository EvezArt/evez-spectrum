## 8. STRONGEST COMPOUND PRODUCTS (complete set)

1. AUTONOMY EVIDENCE LOOP: edge telemetry -> event spine -> agent orchestration -> scenario
replay -> simulation -> human review -> signed evidence pack. Customers: robotics, drones,
field autonomy, industrial inspection, aerospace suppliers. The buyer gets an operational
loop for explaining what happened, what the system believed, what action it took, what to
test next. Sell first as architecture/diligence sprint; productize only after one customer
workflow is repeatable.

2. SCIENTIFIC ML VALIDATION COCKPIT: simulation inputs/outputs -> surrogate/model registry ->
validation metrics -> confidence and provenance -> decision memo. Customers: engineering
R&D, climate/energy simulation, materials, aerospace design, industrial digital twins. Wedge:
independent validation and reproducibility, not another model platform.

3. PQC MIGRATION EVIDENCE GRAPH: code/dependency/device inventory -> cryptographic-use graph ->
risk prioritization -> interoperability test evidence -> migration backlog. Customers: device
makers, SaaS/platform companies, critical infrastructure suppliers, security teams. Align
language with NIST discovery and interoperability workstreams.

4. DEEP-TECH CLAIM LEDGER: company claims -> architecture evidence -> benchmark and baseline
-> failure modes -> key experiment -> investment/customer decision. Customers: deep-tech VCs,
corporate venture, quantum companies, strategic partners. The clearest route to a repeatable
diligence product; uses EVEZ provenance concepts without requiring client stack adoption.

5. GOVERNED AGENT OPERATIONS KIT: agent roles -> policy/constitution -> tool permissions ->
event spine -> contradiction detection -> audit/replay. Customers: teams deploying
multi-agent systems where accountability matters. Position as architecture and operating
model first. Do NOT imply governance documents alone make an agent system safe.

## 9. COMPETITIVE POSITIONING

THE POSITION TO OWN: Independent technical assurance for deep-tech systems that combine AI,
simulation, autonomy, cryptography, and evidence.

Category map: big consultancies (breadth, procurement familiarity, expensive, strategy
separated from hands-on evidence) | specialist engineering firms (vertical depth, less
independent when assessing vendors/theses) | academic experts (domain authority, rarely
package decision artifacts) | AI-platform vendors (sell compute, not neutral assessors) |
general fractional CTOs (startup strategy, without scientific validation + provenance +
PQC + autonomy evidence).

Credible claim: cross-domain synthesis plus inspectable artifacts. Solo-specialist
advantage: speed, direct senior attention, no large-team overhead, independence from a
platform vendor. Risks: capacity, key-person dependency, security maturity, no formal
certifications. Mitigations: fixed scopes, clear exclusions, secure handling procedures,
professional references, partner bench for regulated work.
